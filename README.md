# Jonathan Angel

I build applications that turn incoming information into evidence, decisions, and working operational flows.

## Selected projects

| Project | What you can inspect |
| --- | --- |
| [JD Direct](https://github.com/jonathanangel-1/jd-direct-public) | Email-to-shipment intake, document scanning and metadata forensics, carrier screening, Persona identity verification, and controlled release. |
| [PQ Ops](https://github.com/jonathanangel-1/pq-ops-public) | A shipment control room combining source evidence, shipment state, operator decisions, and integration code. |
| [Angie](https://github.com/jonathanangel-1/angie-public) | Inspiration-to-product recommendations, fit guidance, confirmed feedback, saved looks, and learning from outcomes. |

Each repository includes application source, an architecture guide, screenshots, and a local demo. The public editions use fictional data and omit service credentials. External service simulations are labeled in the demos and documentation.
